# Моя візитка

Переглянути сайт "Моя візитка".
Це мій персональний сайт-візитка, створений за допомогою HTML, CSS та AI-агента Cursor. На сайті розміщено інформацію про мене, мої навички та контакти.

## Використані технології
- HTML — структура сайту.
- CSS — оформлення та дизайн.
- Cursor AI — допомога у створенні коду.
- Git — збереження версій проєкту.
- GitHub — зберігання проєкту онлайн.

## Як запустити сайт
1. Завантажити файли проєкту.
2. Відкрити файл index.html у браузері.

## Нова функціональність

За допомогою Cursor AI додано перемикач світлої та темної теми сайту. Користувач може змінювати оформлення натисканням кнопки.

Для безпечної роботи створено файл .env із демонстраційним API-ключем. Файл .gitignore запобігає завантаженню .env на GitHub.

Під час роботи було протестовано зміну кольору кнопки та скасовано її за допомогою Git без втрати основної функціональності.
